# Base fixa (fase 1)

Tudo o que o laboratório assume sobre o mundo: cargas, tecnologia, preços e
concorrentes. Cada parâmetro tem rótulo, faixa e fonte. Os designs de chip
NÃO ficam aqui.

Rótulos permitidos:

| rótulo | significado |
|---|---|
| MEDIDO | medido por nós ou por terceiro com dado bruto disponível |
| PUBLICADO | número publicado por fabricante, padrão ou fonte primária (link obrigatório) |
| CALIBRADO | ajustado contra dado real, com erro registrado |
| DERIVADO | calculado a partir de outros parâmetros (fórmula registrada) |
| ESTIMADO | estimativa de mercado ou nossa, com faixa |
| HIPÓTESE | premissa sem evidência direta, com faixa obrigatória |
| UNKNOWN | desconhecido; não pode ser usado sem virar HIPÓTESE com faixa |

Unidades monetárias em US$ dentro do laboratório (é a moeda das fontes);
os relatórios para o Renan convertem para R$.

Origem: os blocos de insumo da AMA (`AMA512_INPUT_*.md`, set/2026), revisados
e atualizados com fontes de nov/2026 quando o mercado mudou.
